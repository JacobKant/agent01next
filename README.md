# Agent01Next - AI Чат с расширенными возможностями

Интеллектуальный чат-бот на базе Next.js с поддержкой множественных LLM провайдеров, расширяемой функциональности через MCP (Model Context Protocol) и RAG (Retrieval-Augmented Generation).

## 🎯 Назначение проекта

Проект представляет собой полнофункциональную платформу для взаимодействия с AI моделями, которая включает:

- **Мультипровайдерность**: Поддержка OpenRouter API и кастомных провайдеров
- **Расширяемость**: Интеграция через MCP серверы для добавления новых инструментов
- **RAG**: Семантический поиск по индексированным документам
- **Планировщик задач**: Автоматическое выполнение задач по расписанию
- **История чатов**: Сохранение и управление сессиями диалогов

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Настройка переменных окружения

Скопируйте пример файла настроек:

```bash
cp env.local.example .env.local
```

Отредактируйте `.env.local` и добавьте необходимые ключи:

```env
OPENROUTER_API_KEY=sk-or-xxxxxxxxxxxxxxxxxxxxxxxxxxxx
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 3. Запуск приложения

```bash
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## 🔧 Основные компоненты

### Роли ассистента

Проект поддерживает несколько специализированных ролей ассистента:

- **default**: Универсальный ассистент поддержки
- **team-assistant**: Командный ассистент для управления проектом через GitHub Issues
- **data-analyst**: Локальный аналитик данных (анализ CSV, JSON, логов)
- **personal-assistant**: Персональный ассистент для помощи в работе, здоровье, развитии (использует персональный профиль)

### MCP (Model Context Protocol) Серверы

Проект использует MCP для расширения функциональности AI через внешние инструменты:

- **cbr-rates-server**: Получение курсов валют ЦБ РФ
- **web-fetch-server**: Веб-поиск и получение контента с сайтов
- **file-server**: Работа с файловой системой
- **rag-search-server**: Семантический поиск по индексированным документам

Подробнее: [doc/MCP_SERVERS.md](doc/MCP_SERVERS.md)

### RAG (Retrieval-Augmented Generation)

Система семантического поиска по документам с использованием векторной базы данных Vectra:

- Индексация документов с разбивкой на чанки
- Генерация эмбеддингов через OpenRouter API
- Семантический поиск по индексированным документам

Подробнее: [doc/RAG_INDEXER.md](doc/RAG_INDEXER.md)

### Планировщик задач

Автоматическое выполнение задач по расписанию (cron):

- Проверка курсов валют
- Отправка уведомлений в Telegram
- Выполнение произвольных задач с использованием AI

Подробнее: [doc/SCHEDULER.md](doc/SCHEDULER.md)

### База данных

SQLite база данных для хранения:

- Сессий чатов (chats)
- Сообщений с метаданными (messages)
- История использования инструментов

## 👤 Персонализация агента

Агент может быть настроен под ваши личные предпочтения, стиль работы и цели. Для этого создайте файл `personal-profile.json` в корне проекта на основе `personal-profile.example.json`.

**Важно**: Файл `personal-profile.json` автоматически игнорируется git (добавлен в `.gitignore`), чтобы персональные данные не попали в публичный репозиторий.

### Настройка персонализации

1. Скопируйте пример файла:
   ```bash
   cp personal-profile.example.txt personal-profile.txt
   ```

2. Заполните файл `personal-profile.txt` своими данными в свободной форме:
   - Опишите себя, свои предпочтения и стиль работы
   - Укажите цели и вызовы
   - Добавьте информацию о том, как вы предпочитаете общаться
   - Опишите, в чем нужна помощь от ассистента
   
   Формат файла - обычный текст, структурируйте как удобно. Можно использовать пример из `personal-profile.example.txt` как ориентир.

3. После создания файла агент автоматически будет использовать эту информацию для:
   - Персонализации ответов
   - Учета ваших предпочтений в общении
   - Помощи в достижении ваших целей
   - Адаптации стиля общения под ваш темперамент

Персонализация применяется ко всем ролям ассистента. Роль **personal-assistant** специально создана для максимального использования персонального профиля и фокусируется на помощи в личных целях, работе, здоровье и развитии.

**Важно**: Файл `personal-profile.txt` автоматически игнорируется git (добавлен в `.gitignore`), чтобы персональные данные не попали в публичный репозиторий.
