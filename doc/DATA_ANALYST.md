# Локальный аналитик данных

## Описание

Локальный аналитик данных позволяет анализировать CSV, JSON и лог-файлы полностью локально, без использования облачных сервисов.

## Возможности

- Загрузка файлов данных (CSV, JSON, LOG, TXT)
- Анализ структуры данных
- Статистика по данным
- Поиск в данных
- Анализ ошибок в логах

## Использование

### 1. Выбор роли

В интерфейсе чата выберите роль **"Аналитик"**.

### 2. Загрузка файлов

1. После выбора роли "Аналитик" появится поле для загрузки файлов
2. Нажмите "Выбрать файл" и выберите файл (CSV, JSON, LOG или TXT)
3. Файл будет загружен в директорию `data/analyst/`

### 3. Анализ данных

Задайте вопросы модели на русском языке:

**Примеры вопросов:**
- "Какие файлы загружены?"
- "Какая ошибка встречается чаще всего в логах?"
- "Покажи статистику по продажам"
- "Найди все записи с ошибкой timeout"
- "Какие регионы лидируют по продажам?"

## Доступные инструменты

### list_data_files
Получить список всех загруженных файлов.

### load_data_file
Загрузить и просмотреть структуру файла (колонки, примеры данных).

**Параметры:**
- `fileName` - имя файла

### get_data_statistics
Получить статистику по данным (частота значений, уникальные значения).

**Параметры:**
- `fileName` - имя файла
- `column` (опционально) - конкретная колонка для анализа

### search_data
Поиск в данных по текстовому запросу.

**Параметры:**
- `fileName` - имя файла
- `query` - текст для поиска
- `column` (опционально) - конкретная колонка для поиска
- `limit` (опционально) - максимальное количество результатов

### analyze_errors
Анализ ошибок в лог-файлах (группировка по типам, топ ошибок).

**Параметры:**
- `fileName` - имя файла лога

## Форматы данных

### CSV
Табличные данные с разделителями (запятая или точка с запятой).

**Пример:**
```csv
date,product,quantity,price
2026-01-01,Product A,10,100.50
2026-01-02,Product B,5,250.00
```

### JSON
Структурированные данные в формате JSON.

**Пример:**
```json
[
  {"date": "2026-01-01", "product": "Product A", "quantity": 10},
  {"date": "2026-01-02", "product": "Product B", "quantity": 5}
]
```

### LOG/TXT
Текстовые файлы и логи. Каждая строка - отдельная запись.

**Пример:**
```
[2026-01-20 10:15:23] ERROR: Database connection timeout
[2026-01-20 10:16:45] WARNING: High memory usage detected
```

## Технические детали

- **Хранилище:** `data/analyst/` (локальная директория)
- **MCP сервер:** `data-analyst-server.ts`
- **Парсер данных:** `data-parser.ts`
- **API endpoints:**
  - `POST /api/data/upload` - загрузка файла
  - `GET /api/data/files` - список файлов

## Примеры использования

### Анализ ошибок в логах

```
Пользователь: "Какая ошибка встречается чаще всего в example_errors.log?"

AI:
1. Использует list_data_files для проверки файлов
2. Использует load_data_file для понимания структуры
3. Использует get_data_statistics для анализа частоты ошибок
4. Отвечает: "Самая частая ошибка: 'Database connection timeout' (3 раза)"
```

### Статистика по продажам

```
Пользователь: "Покажи статистику по продажам в example_sales.csv"

AI:
1. Использует load_data_file для загрузки данных
2. Использует get_data_statistics для получения статистики
3. Отвечает с анализом по регионам, продуктам, количеству
```

## Ограничения

- Максимальный размер файла ограничен настройками сервера
- Все данные обрабатываются локально (без облака)
- Поддерживаются только текстовые форматы (CSV, JSON, LOG, TXT)
