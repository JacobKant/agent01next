# FAQ - Часто задаваемые вопросы

## Общие вопросы

### Что такое agent01next?
agent01next - это AI-чат приложение с расширенными возможностями, построенное на Next.js 14, TypeScript, SQLite, Vectra и MCP (Model Context Protocol). Проект предоставляет интеллектуального ассистента с поддержкой RAG поиска, планировщика задач и интеграции с различными сервисами.

### Какие технологии используются в проекте?
- **Next.js 14** - фреймворк для веб-приложений
- **TypeScript** - типизированный JavaScript
- **SQLite** - база данных для хранения истории чатов
- **Vectra** - векторная база данных для RAG поиска
- **MCP (Model Context Protocol)** - протокол для интеграции различных сервисов
- **OpenRouter** - API для доступа к различным LLM моделям

## Авторизация и вход

### Почему не работает авторизация?
Если у вас проблемы с авторизацией, проверьте следующее:

1. **Проверьте API ключи**: Убедитесь, что в файле `.env.local` установлен `OPENROUTER_API_KEY`
2. **Проверьте формат ключа**: API ключ должен быть валидным и не содержать лишних пробелов
3. **Проверьте подключение к интернету**: OpenRouter требует активного интернет-соединения
4. **Проверьте лимиты API**: Возможно, превышен лимит запросов к OpenRouter

Если проблема сохраняется, создайте тикет в системе поддержки с описанием ошибки.

### Как получить API ключ OpenRouter?
1. Зарегистрируйтесь на сайте [OpenRouter.ai](https://openrouter.ai)
2. Перейдите в раздел "Keys" в вашем профиле
3. Создайте новый API ключ
4. Скопируйте ключ и добавьте его в файл `.env.local` как `OPENROUTER_API_KEY=ваш_ключ`

## RAG поиск

### Как работает RAG поиск?
RAG (Retrieval-Augmented Generation) поиск использует семантический (векторный) поиск для нахождения релевантной информации в документации проекта. 

Процесс работы:
1. Ваш запрос преобразуется в векторное представление (эмбеддинг)
2. Система ищет наиболее похожие фрагменты текста в индексированной документации
3. Найденные фрагменты используются как контекст для генерации ответа

### Почему RAG поиск не находит нужную информацию?
Возможные причины:
- Документация еще не проиндексирована - запустите индексацию через `document_indexer`
- Запрос слишком специфичный - попробуйте использовать более общие ключевые слова
- Информация отсутствует в документации - добавьте нужную информацию в файлы в папке `doc/`

### Как переиндексировать документацию?
1. Перейдите в папку `document_indexer`
2. Убедитесь, что установлены зависимости: `npm install`
3. Запустите индексацию: `npm run index` или `tsx index.ts`
4. Дождитесь завершения процесса

## MCP серверы

### Что такое MCP серверы?
MCP (Model Context Protocol) серверы - это модули, которые предоставляют дополнительные инструменты для AI ассистента. В проекте доступны следующие серверы:

- **RAG Search Server** - поиск в документации
- **File Server** - работа с файлами
- **Git Server** - работа с Git репозиторием
- **Web Server** - получение информации из интернета
- **CRM Server** - доступ к данным пользователей и тикетам

### Как добавить новый MCP сервер?
1. Создайте файл сервера в папке `src/mcp/`
2. Реализуйте сервер используя `@modelcontextprotocol/sdk`
3. Добавьте конфигурацию сервера в `src/lib/mcp-client.ts`

## Планировщик задач

### Что такое планировщик задач?
Планировщик задач позволяет автоматически выполнять задачи по расписанию. Например, можно настроить периодическую проверку курсов валют или отправку уведомлений.

### Как создать новую задачу?
1. Создайте файл задачи в `src/lib/tasks/`
2. Реализуйте функцию задачи
3. Зарегистрируйте задачу в `src/lib/tasks/index.ts`
4. Настройте расписание через API `/api/scheduler/start`

## История чатов

### Где хранится история чатов?
История чатов хранится в базе данных SQLite. Файл базы данных находится в корне проекта.

### Как очистить историю чатов?
Историю можно очистить через API или напрямую в базе данных SQLite. Будьте осторожны - это действие необратимо.

## Технические проблемы

### Ошибка "Индекс не найден"
Эта ошибка означает, что RAG индекс еще не создан. Запустите индексацию документации через `document_indexer`.

### Ошибка "MCP сервер не подключен"
Проверьте:
1. Что все зависимости установлены: `npm install`
2. Что переменные окружения настроены правильно
3. Логи консоли для детальной информации об ошибке

### Проект не запускается
1. Проверьте, что установлены все зависимости: `npm install`
2. Убедитесь, что Node.js версии 18 или выше
3. Проверьте наличие файла `.env.local` с необходимыми переменными
4. Проверьте логи ошибок в консоли

## Поддержка

### Как создать тикет в поддержку?
Используйте функцию создания тикета через CRM MCP сервер. Ассистент может помочь вам создать тикет с описанием проблемы.

### Как проверить статус моего тикета?
Используйте функцию поиска тикета через CRM MCP сервер. Ассистент может найти информацию о вашем тикете по номеру или описанию.

## Разработка

### Как добавить новую функциональность?
1. Изучите архитектуру проекта в `doc/ARCHITECTURE.md`
2. Создайте необходимые компоненты
3. Добавьте документацию в папку `doc/`
4. Обновите RAG индекс после добавления документации

### Где найти документацию по архитектуре?
Вся документация находится в папке `doc/`:
- `ARCHITECTURE.md` - общая архитектура проекта
- `MCP_SERVERS.md` - документация по MCP серверам
- `RAG_INDEXER.md` - документация по RAG индексации
- `SCHEDULER.md` - документация по планировщику задач
- `SETUP.md` - инструкции по настройке
